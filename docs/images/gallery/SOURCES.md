# Gallery Image Sources

This file records the source, license and attribution for each image
under `docs/images/gallery/` and each `cover-*.jpg` referenced from
`docs/gallery.md`. Until each entry is filled in below, the
corresponding image is to be treated as **"source not verified"**
and **must not** be redistributed outside this site.

If you are the rights holder for any image below and want a change
(attribution correction, different license, or removal), please open
an issue or contact the author using the details in
[`/SECURITY.md`](../../../SECURITY.md) and
[`/NOTICE`](../../../NOTICE).

## Format

Each entry follows:

```markdown
### wallpaper-XX.jpg
- Source: <URL or "author original">
- Author: <author or rights holder>
- License: <SPDX identifier, e.g. CC0, CC-BY-4.0, MIT, custom>
- Note: <short comment, optional>
```

## Guidelines

- Use only images you have the right to publish. Prefer original
  screenshots, CC0/public-domain images, or images whose license
  (Creative Commons, MIT for icon files, etc.) permits redistribution
  with attribution.
- Where an image's license requires attribution, the related Markdown
  post must display the attribution block alongside the image.
- Where an image's license is **non-commercial only** (e.g. CC BY-NC-*),
  it must not be republished under the CC BY-NC-SA license used for
  the rest of the site's prose; pin it to the specific page and add a
  visible notice.
- Where an image's license is unclear or unknown, do not include it
  in this repository. Replace it with placeholder text or remove the
  reference until verified.
