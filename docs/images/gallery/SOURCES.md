# Gallery Image Sources

All images under `docs/images/gallery/` were removed pending source
verification. See `docs/content-policy.md` §3 ("Third-party content")
for the rules every future entry must satisfy before being re-added.

If you want to repopulate the gallery, restore images only after:

- the original source URL or "author original" is recorded;
- the rights holder and license (SPDX, e.g. CC0, CC-BY-4.0, MIT) are
  identified;
- attribution is shown next to the image when the license requires it;
- non-commercial-only licenses (e.g. CC BY-NC-*) are pinned to a single
  page with a visible notice, since the rest of the site is published
  under CC BY-NC-SA 4.0.

Report problems via the channels listed in
[`/SECURITY.md`](../SECURITY.md) and [`/NOTICE`](../NOTICE).
